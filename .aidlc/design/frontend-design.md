# 前端设计

## 1. 路由与信息架构

```
/                          → 重定向到 /login 或角色首页
/login                     → 登录页面
/register                  → 注册页面（含角色选择）

/user                      → 用户首页（推荐+热门）
/user/explore              → 浏览所有优惠券（含搜索/筛选）
/user/coupons              → 我的券包
/user/favorites            → 收藏夹
/user/notifications        → 通知列表
/user/ranking              → 排行榜

/operator                  → 运营首页（活动概览）
/operator/campaigns        → 活动列表管理
/operator/campaigns/create → 创建活动（含AI文案）
/operator/campaigns/:id    → 编辑活动
/operator/templates        → 活动模板
/operator/batch            → 批量发券
/operator/blacklist        → 黑白名单管理

/verifier                  → 核销首页
/verifier/verify           → 核销操作页面
/verifier/records          → 核销记录

/admin                     → 管理员首页
/admin/dashboard           → 统计面板（图表）
/admin/logs                → 操作日志
/admin/export              → 数据导出
/admin/risk                → 风控监控
/admin/profiles            → 用户画像

/share/:code               → 分享领券页面（无需特定角色登录后可领）
```

## 3. 通用组件清单

| 组件 | 用途 |
|------|------|
| `<CouponCard>` | 优惠券展示卡片（进度条、类型标签、操作按钮） |
| `<ProgressBar>` | 库存进度条 |
| `<RoleGuard>` | 路由权限守卫 |
| `<NotificationBell>` | 通知铃铛+弹出面板 |
| `<DataTable>` | 通用数据表格（分页、排序、筛选） |
| `<StatsCard>` | 统计数字卡片 |
| `<ChartWrapper>` | Recharts图表容器 |
| `<AILoadingState>` | AI加载中状态（带动画） |
| `<EmptyState>` | 空数据占位 |
| `<FormField>` | 统一表单字段样式 |
| `<Modal>` | 弹窗 |
| `<Toast>` | 操作反馈提示 |

## 4. 状态管理

- 认证状态：React Context（AuthContext）存储用户信息+JWT
- 通知状态：React Context（NotificationContext）存储未读数
- 页面数据：各页面通过 SWR / fetch 直接请求API，无需全局状态管理
- 表单状态：React Hook Form 或原生useState

## 5. 交互规范

- 按钮加载状态：操作进行中禁用按钮 + loading spinner
- AI操作：显示专门的AI加载动画（骨架屏/脉冲点）
- 成功操作：Toast提示 + 自动刷新列表
- 错误处理：Toast红色提示 + 保留用户输入
- 确认操作：删除/转赠等不可逆操作弹确认框
- 响应式：移动端自适应（TailwindCSS responsive）

## 6. 视觉风格

- **配色**：主色调蓝色系（专业稳重），辅色绿色（成功）、红色（错误/拦截）、橙色（警告）
- **字体**：系统默认字体栈
- **间距**：TailwindCSS spacing scale
- **卡片**：圆角(rounded-lg) + 阴影(shadow-sm) + 白色背景
- **图标**：Lucide React 图标库
