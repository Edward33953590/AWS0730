## 配置说明

`assets.json` 定义了每张背景图的元数据，包括：
- `text_area`: 文案叠加区域坐标（x, y, width, height）
- `text_color`: 推荐文字颜色
- `recommended_font_size`: 推荐字号

## 添加新背景图

1. 将图片文件放入本目录
2. 在 `assets.json` 中添加对应条目
3. 也可通过管理后台上传（会自动注册到数据库）
