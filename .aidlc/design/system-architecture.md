## 2. 分层架构说明

| 层级 | 职责 | 技术 |
|------|------|------|
| 展示层 | 页面渲染、用户交互、表单、图表 | React + TailwindCSS + Recharts |
| API层 | 路由处理、参数校验、权限检查、响应格式化 | Next.js API Routes |
| 服务层 | 核心业务逻辑、AI调用、风控引擎 | TypeScript Classes/Functions |
| 数据层 | 数据库操作、事务管理、ORM映射 | Prisma ORM |
| 存储层 | 持久化数据 | SQLite (WAL模式) |
| 外部服务 | AI推理 | Amazon Bedrock Converse API |

## 3. 核心模块划分

### 3.1 认证模块 (Auth)
- 注册/登录/令牌签发
- JWT中间件（验证+角色提取）
- 角色权限守卫

### 3.2 活动管理模块 (Campaign)
- 活动CRUD
- 模板管理
- 参数校验（类型相关）

### 3.3 优惠券模块 (Coupon)
- 领券（原子库存扣减）
- 券码生成
- 转赠
- 分享链接
- 状态管理

### 3.4 核销模块 (Redemption)
- 券码核销（幂等）
- 过期/状态校验
- 核销记录

### 3.5 AI服务模块 (AI)
- Bedrock调用封装（SDK/API Key双模式）
- 智能推券
- 文案生成
- 风控评估
- 用户画像
- 异常解释

### 3.6 风控引擎 (Risk)
- AI风控（主路径）
- 规则引擎（降级路径）
- 黑白名单
- 请求频率统计

### 3.7 统计模块 (Stats)
- 数据聚合
- 图表数据
- 数据导出（CSV/Excel）

### 3.8 日志与通知模块 (Log & Notification)
- 操作日志记录
- 通知创建/查询/已读

## 4. 安全边界

```
┌─ 公开接口 ─────────────────────────────┐
│ POST /api/auth/register                │

```

## 5. AI服务集成

```
领券请求 ──→ 风控检测 ──→ AI可用? ──→ [是] Bedrock风控评估
                                    └─→ [否] 规则引擎降级

领券页面 ──→ 智能推荐 ──→ AI可用? ──→ [是] Bedrock推荐+理由
                                    └─→ [否] 热门券列表降级

创建活动 ──→ 文案生成 ──→ AI可用? ──→ [是] Bedrock文案生成
                                    └─→ [否] 预设模板降级
```

## 6. 故障降级策略

| 故障场景 | 降级方案 | 用户感知 |
|----------|----------|----------|
| Bedrock超时(>10s) | 自动降级为规则引擎/默认数据 | 功能正常但结果不如AI精准 |
| Bedrock报错 | 捕获异常，返回降级结果 | 同上 |
| SQLite写入竞争 | 事务重试（最多3次） | 用户无感知 |
| JWT过期 | 前端检测401，跳转登录页 | 提示重新登录 |
