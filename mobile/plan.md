## 一、目标

实现手机扫码核销闭环：用户展示二维码 → 核销员扫码 → 自动核销。提升竞赛演示冲击力。

## 二、架构概览

```
用户手机                   核销员手机
┌─────────────┐           ┌──────────────┐
│ 优惠券详情页 │──二维码──→│ 相机扫码      │
│ qrcode.js   │    URL    │ /v/CPN-XXXX  │
└─────────────┘           └──────┬───────┘
                                 │
                    ┌────────────┴────────────┐
                    │ 已登录 + VERIFIER → 自动核销 │
                    │ 未登录 → 内嵌登录 → 自动核销 │
                    │ 已登录非核销员 → 提示权限不足 │
                    └────────────┬────────────┘
                                 ▼
                        ┌────────────────┐
                        │ POST /api/redeem│
                        │ 已有接口，不改   │
                        └────────────────┘
```
