### 2️⃣ 查询测试数据

```

优惠券: CPN-455O33B7(CLAIMED), CPN-NJLZ3HLE(REDEEMED), ...
```

结果：✅ 数据库中有足够测试数据

### 3️⃣ 未登录状态测试

```bash
# 扫码落地页(未登录) - 应该显示登录页
curl -s http://localhost:5000/v/CPN-455O33B7
# → HTTP 200, 页面标题: "核销员登录 - 优惠券中心"
```

结果：✅ 未登录时显示内嵌登录页，券码已预填

### 4️⃣ 核销员登录

```bash
curl -s -c /tmp/cookies.txt http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"verifier","password":"verifier123"}'
```

结果：✅ 登录成功，返回 `success: true`

### 5️⃣ 已登录状态测试

```bash
# 扫码落地页(已登录) - 应该自动核销
curl -s -b /tmp/cookies.txt http://localhost:5000/v/CPN-455O33B7
# → HTTP 200, 页面标题: "扫码核销 - 优惠券中心", 显示"正在核销..."
```

结果：✅ 已登录时自动触发核销

### 6️⃣ 核销API测试

```bash
# 正常核销
curl -s -b /tmp/cookies.txt http://localhost:5000/api/redeem \
  -H "Content-Type: application/json" \
  -d '{"coupon_code":"CPN-455O33B7"}'
# → success: true, status: REDEEMED, redeemed_at: 2026-07-30T04:33:42

# 重复核销(幂等)
curl -s -b /tmp/cookies.txt http://localhost:5000/api/redeem \
  -H "Content-Type: application/json" \
  -d '{"coupon_code":"CPN-NJLZ3HLE"}'
# → success: true, status: ALREADY_REDEEMED

# 无效券码
curl -s -b /tmp/cookies.txt http://localhost:5000/api/redeem \
  -H "Content-Type: application/json" \
  -d '{"coupon_code":"CPN-INVALID"}'
# → success: false, error.message: "无效券码"
```

结果：✅ 三个场景全部通过

### 7️⃣ 用户端测试

```bash
# 以 user1 身份登录
curl -s -c /tmp/cookies3.txt http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user1","password":"user123"}'

# 访问优惠券详情页

# 核销员访问用户详情页

# → HTTP 302, 权限隔离正常
```

结果：✅ 用户详情页正常，权限控制正常
